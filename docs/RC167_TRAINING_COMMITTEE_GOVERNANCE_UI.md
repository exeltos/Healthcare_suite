# Healthcare Suite rc.167 — Training, Committee & Governance UI refinement

- Training editor split into Details, Attendance, Assessment, and Material & Notes tabs.
- Participant selector now uses the shared SearchInput control.
- Attendance records presence only; scores and competency evidence moved to Assessment.
- Committee meetings now support structured agenda topics with presenter, discussion summary and per-topic decision.
- Existing committee meeting records remain backwards-compatible when no agendaItems exist.
- Governance notification and retention policy editors now use FormGrid/FormField controls and shared control geometry.
- Governance audit search now uses the shared SearchInput.
