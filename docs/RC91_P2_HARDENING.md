# Healthcare Suite rc.91 — P2 hardening

This batch completes the next non-blocking hardening layer without adding steps to daily clinical workflows.

## Antimicrobial stewardship
- Restricted/promoted antibiotics are integrated into the central indicator engine.
- Automatic approval-rate indicator.
- Automatic pending-requests indicator.
- Both are included in the comparative Analytics antimicrobial view.
- Indicator screens refresh on promoted-antibiotic changes.

## Governance / ISO-JCI support
- Governance Center now exposes a compact readiness strip for notification policies, retention ownership, backup/recovery testing, privacy documentation and competency gaps.
- This is administrative oversight only and does not add fields to clinical forms.

## Notifications
- Notification Center chrome is bilingual.
- Policy-driven escalation thresholds now visibly mark overdue governed notifications as escalated.
- Existing role filtering and closed-loop critical-result logic are retained.

## Quality / traceability already preserved
- Immutable audit trail.
- Critical laboratory result communication requires recipient and timestamp.
- CAPA / incident / audit relationships remain intact.
- Controlled document history, competency gaps, retention, privacy and recovery evidence remain governed.
